# Mother's Day site

A small static site — a Mother's Day gift from Ambrose to Mom.

## What's in here

- `index.html` — the page
- `style.css` — the styling
- `images/` — photos used on the page
  - `images/stories/` — photos for each story
  - `images/school/` — photos of school work

## Viewing locally

Open `index.html` in any web browser. No build step, no server.

## Hosting

Deployed via GitHub Pages from this repo. Live URL is set in the repo's Pages settings.
